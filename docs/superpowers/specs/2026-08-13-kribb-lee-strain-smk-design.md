# KRIBB 이지영 균주 SMK 및 랜딩 개편 명세

## 목표

- 기존 01 박승환 균주소개서는 변경하지 않는다.
- 02 이지영 균주소개서는 기존 KIST·블루포인트·가톨릭대학교 SMK 계열의 16:9 단면 템플릿으로 제작한다.
- 랜딩페이지의 기술 카드 목록은 5열 표 목록으로 교체한다.
- 정적 GitHub Pages에서 서버 없이 동작하도록 HTML·CSS·JavaScript·JSON·이미지만 사용한다.

## 원문 기준

- 원문: `02_기술소개서(이지영)_균주.pptx`
- PPT의 세부 문안, 수치, 목차명은 표현을 임의로 바꾸지 않고 그대로 사용한다.
- PPT에 포함된 관련 데이터 이미지 2개를 원본 추출하여 사용한다.
- 이미지에 없는 별도 실험 데이터나 시장자료를 추가하지 않는다.

## 랜딩페이지

- 카드형 목록을 표형 목록으로 교체한다.
- 열은 다음 5개로 고정한다.
  1. 특허명
  2. 출원번호
  3. 기탁번호
  4. 균주명
  5. 보러가기
- 01 박승환과 02 이지영 기술을 각 1행으로 표시한다.
- 데스크톱은 전체 표를 한 화면 폭에 배치한다.
- 모바일은 글자를 축소하거나 음절 단위로 자르지 않고 가로 스크롤로 전환한다.
- 각 행의 보러가기 버튼은 해당 기술소개서로 연결한다.

## 01 박승환 소개서

- 현재 `smk.html?tech=park-1020220067778` 화면과 A4 세로 2페이지 인쇄 구성을 유지한다.
- 이번 변경으로 01의 DOM, CSS, 데이터, 인쇄 배치가 달라지지 않도록 회귀 검증한다.

## 02 이지영 소개서

- 별도의 기존형 16:9 SMK 렌더러를 사용한다.
- 한 화면은 기존 KIST·블루포인트·가톨릭대학교 SMK의 정보 위계와 그리드 체계를 재사용한다.
- 인쇄는 A4 가로 1페이지로 고정한다.
- 다음 PPT 목차를 그대로 사용한다.
  1. 균주 정보
  2. 특허 정보
  3. 실험 정보
  4. 관련 데이터
  5. 기술우위성 및 고도화 필요사항
  6. 적용제품 시나리오
  7. 기술활용 절차
  8. 연구자 보유 균주 및 특허
- 제목은 `염 스트레스 내성 Pseudomonas sp. JBR1 균주기반 농업 미생물 플랫폼`을 사용한다.
- 연구자는 `생물자원센터 이지영 박사`로 표시한다.
- 04 관련 데이터에는 PPT 원본 이미지 2개와 원본 캡션을 사용한다.
- 05는 기술우위성과 고도화 필요사항을 좌우 비교 구조로 표시한다.
- 06은 PPT의 5개 적용제품 시나리오를 표로 표시한다.
- 07은 PPT의 4단계 기술활용 절차를 연결형 프로세스로 표시한다.
- 08은 PPT의 연구자 보유 균주 및 특허 3건을 표로 표시한다.

## 데이터와 링크

- `data/technologies.json`에 이지영 기술을 공개 기술로 추가한다.
- 랜딩 목록은 JSON에서 두 기술을 읽어 표 행을 만든다.
- 01은 현재 세로형 템플릿 링크를 유지한다.
- 02는 기존형 SMK 템플릿 링크로 분기한다.
- JSON에 템플릿 유형과 랜딩 표시 필드를 명시하여 이후 03번부터 동일 방식으로 추가할 수 있게 한다.

## 줄바꿈과 가독성

- 한국어는 `word-break: keep-all`을 적용한다.
- 균주명, 기탁번호, 농도·수치·단위는 의미 단위가 갈라지지 않도록 보호한다.
- 제목과 표 머리글은 의도하지 않은 줄바꿈이 발생하지 않게 한다.
- PPT 원본의 세부내용을 유지하되, 화면 안에서 읽을 수 없는 크기로 축소하지 않는다.

## 검증

- 랜딩 데스크톱·태블릿·모바일에서 표 열, 링크, 오버플로를 확인한다.
- 01 화면 및 A4 세로 2페이지 인쇄가 기존과 동일한지 확인한다.
- 02 화면에서 목차 8개, 세부 문안, 수치, 이미지 2개가 모두 표시되는지 확인한다.
- 02 A4 가로 PDF가 정확히 1페이지인지 확인한다.
- 텍스트·이미지·표·도형의 겹침과 잘림이 없는지 실제 브라우저와 PDF 렌더로 확인한다.
- GitHub Pages 배포 후 랜딩, 01, 02 공개 URL을 직접 열어 확인한다.

## 정리 범위

- 배포 구동에 필요한 HTML·CSS·JavaScript·JSON·이미지는 보존한다.
- 사용자가 제공한 PPT·PDF 원문과 기존 프로젝트 파일은 삭제하지 않는다.
- 이번 작업 중 생성한 임시 PPT 복사본, 압축 해제 폴더, 검사 JSON, 임시 스크린샷, 임시 PDF만 식별한다.
- 식별한 임시 산출물은 경로를 검증한 뒤 Windows 휴지통으로 이동한다.
